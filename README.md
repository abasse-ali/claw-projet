# Projet Atelier de la Fourmi

Automatisation de la mise en ligne des produits sur Amazon et CDiscount depuis www.atelierdelafourmi.fr

## Installation

```bash
pip install -r requirements.txt
```

## Utilisation

```bash
python main.py --help
```

## Configuration

Copier `.env.example` vers `.env` et remplir les identifiants API.
